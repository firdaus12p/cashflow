# Target Tabungan sebagai Progres Virtual Tanpa Pemotongan Saldo

Target tabungan dicatat sebagai indikator progres virtual yang tidak mengunci atau memotong saldo dompet pengguna saat top-up dilakukan. Karena aplikasi berfungsi sebagai pencatatan manual offline dan partisi dana fisik/digital sudah ditangani oleh sistem Pos Keuangan, memotong saldo dompet untuk target tabungan akan memicu kebingungan pencatatan ganda ketika uang fisik di dunia nyata belum tentu dipindahkan ke rekening terpisah.
